# Template variables

仅用于绑定群体名称、用途、人数、角色信息、风格和色彩等 【】 槽位；不得发送给图像工具。

---

# Image prompt

```text
16:9横向群像角色设定展示板，character group presentation board，ensemble character lineup，faction lineup poster，cinematic character concept sheet。

整体采用高级东方幻想游戏角色设定集与影视美术角色海报的排版方式。画面以浅灰白色为背景，整体留白充足，构图庄重、整齐、统一、高级。使用极细浅灰蓝色双线装饰边框，四角加入简洁精致的东方传统纹样装饰，边框对称、克制，不使用复杂花纹。

画面顶部中央设置大型中文主标题：

“【群体名称】｜【场景或用途】”

标题使用深蓝灰色高级宋体或现代中文衬线字体，字号较大，字距舒展，居中排列。标题左右可以加入小型对称东方纹章、卷云纹或装饰符号。

画面中央为多人横向群像展示区，占画面主体高度约65%–70%。展示【人数】名属于同一阵营、组织、门派、团队或家庭的角色。所有角色并排站立或轻微错落排列，形成完整横向队列。

角色之间需要有清晰的前后层次和身高差异，但不能互相严重遮挡。每个角色都应完整展示头部、服装、手部和脚部，人物下方保持统一的落地阴影。角色姿态自然、自信、具有身份差异，可包含抱臂、持剑、叉腰、抬手、自然站立等轻微变化，但整体构图保持统一。

所有角色必须保持同一视觉世界观、同一光线方向、同一材质表现、同一摄影棚背景和同一色彩体系。服装可以有所区别，但必须具有统一的阵营识别元素，例如相同色系、相同纹样、相同腰封、相同徽章或相同材质。

角色设定方向：

【人物1：身份、性别、年龄、体型、服装、发型、姿态】

【继续添加角色】

画面底部中央设置一行较小的中文说明文字：

“【群体定位】｜【服装与造型关键词】｜【场景用途】”

整体视觉要求：

浅灰白背景、深蓝灰文字、蓝白或指定阵营色服装、柔和摄影棚光线、真实或半写实3D角色渲染、电影级柔光、统一落地阴影、整齐横向队列、角色身份清晰、阵营统一、个体差异明显、高级东方美学、专业角色展示海报。

禁止出现：

无水印、无Logo、无品牌标志、无多余文字、无错误文字、无复杂背景、无场景杂物、无严重人物遮挡、无重复角色、无身体变形、无多余肢体、无裁切脚部、无风格混杂、无现代物品。
```

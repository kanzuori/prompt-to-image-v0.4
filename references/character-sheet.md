# Template variables

仅用于绑定 【】 槽位：角色主体类型、角色身份、外形特征、体型比例、表面结构、装备、配饰、姿态、气质、视觉风格、色彩与光线。 不得发送给图像工具。

---

# Image prompt

```text
制作一张16:9横向角色设定板，采用专业游戏角色设计稿、影视美术资料板、角色造型设计板和生物设定板的排版方式。

整体为浅灰白色背景，使用极细浅灰色分割线，画面划分为多个规整矩形区域。留白均匀，网格精准对齐，版式干净、高级、专业，整体像高端游戏角色设定集、影视角色定妆资料板和生物概念设计档案。

左侧约占画面60%，分成三个等宽的竖向大栏：

第一栏：主体正面全身或完整形态视图，顶部标题“正面”；
第二栏：主体侧面或侧向形态视图，顶部标题“侧面”；
第三栏：主体背面或后方形态视图，顶部标题“背面”。

三组主体必须是同一个角色或同一种生物，保持完全一致的身份特征、头部或面部结构、体型比例、毛发或外壳、颜色、材质、服装、装备、配饰和道具。

如果主体为人物，展示完整人体比例与服装；
如果主体为动物或幻想生物，展示完整身体结构、四肢、尾巴、翅膀、角、鳞片、羽毛、爪子等特征；
如果主体为机器人、机械体或机甲生命体，展示完整机械结构、外壳、关节、接口和功能部件。

主体采用自然站立、自然停留或符合物种特征的静态姿态，整体形态完整展示，不裁切关键部位，背景为统一的浅灰白色摄影棚或无干扰背景。

右侧约占画面40%，设置主体细节展示区：

顶部横向区域放置两个胸部以上、头部以上或核心结构特写，左右排列，分别标注“正面特写”和“侧面特写”；
中部区域放置两个识别细节图，左侧为表情、头部、面部或视觉特征特写，右侧为眼睛、器官、纹理或核心识别结构特写，分别标注“表情特写”和“主体细节”；
下部设置“服装与结构细节”区域，横向排列4张局部特写，展示【细节部位1】、【细节部位2】、【细节部位3】、【细节部位4】；
最下方设置“发型、外形与配饰细节”区域，横向排列3张局部特写，展示【顶部或正面特征】、【侧面或背面结构】、【关键配饰、装备或道具】。

每个分区顶部预留统一标题位置，图片与文字之间保持适当留白；如模型文字能力不足，标题可不可读或留作后处理，不得因此改变版式。各视图之间保持清晰的视觉对应关系。

主体设定如下：

主体类型：【主体类型】
角色身份：【角色身份】
外形特征：【外形特征】
体型比例：【体型比例】
毛发或表面结构：【毛发或表面结构】
服装或外部装备：【服装或外部装备】
配饰或道具：【配饰或道具】
动作与姿态：【动作与姿态】
气质与性格：【气质与性格】
视觉风格：【视觉风格】
色彩：【色彩】
光线：【光线】
设定板背景：统一浅灰白色摄影棚背景。

整体要求保持同一主体在所有视图中的身份一致，外形结构一致，比例一致，颜色一致，材质一致，服装或装备一致，配饰和道具一致。画面构图整齐，细节清晰，材质真实，符合专业角色设计和影视制作参考需求。

无水印、无Logo、无品牌标志、无多余主体、除规定的区域标题和必要标注外不生成额外文字、无身份变化、无结构变化、无身体变形、无多余肢体、无关键部位裁切、无不相关物品。
```

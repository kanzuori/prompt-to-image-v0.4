# Template variables

仅用于绑定 【】 槽位：具体室内空间、空间类型、内部功能、内部结构、材质、色彩、时间与光线、内部特殊细节。 不得发送给图像工具。

---

# Image prompt

```text
16:9超宽横版【局部空间 / 室内场景】概念设计拆解板，environment detail breakdown sheet，interior production design board，prop and space reference sheet。

主题场景为：【具体室内空间，例如：汽车驾驶舱内部、汽车后排内部、飞机客舱内部、房间内部】。

重要限制：
本设计板只表现【指定空间内部】，不表现建筑外部、城市、道路、赛车场、停车场、远景环境或完整场地。所有图片的摄影机都必须位于该空间内部，镜头视野被空间边界包围。不得从外部拍摄，不得展示整体建筑，不得扩展到空间之外，不得增加主题以外的环境。

如果主题为汽车内部：
只展示车厢内部、驾驶舱、仪表台、中控台、方向盘、座椅、车门内饰、后视镜内部视角、安全带、脚部空间和车内灯光。严禁出现汽车外观、车身全景、车库、道路、赛车道、赛车场、城市街道、停车场或车辆行驶场景。

如果主题为其他封闭空间：
只展示该空间内部的墙面、顶面、地面、内部设备、内部家具、内部装饰和内部功能区域。所有视图必须服务于空间内部结构和材质展示。

俯视图右侧设置深灰黑色图例栏，列出内部功能区域：

①【内部核心区域】
②【内部主要操作区】
③【内部座位或使用区】
④【内部控制设备】
⑤【内部储物或收纳区】
⑥【内部材质区域】
⑦【内部照明区域】
⑧【内部通行区域】
⑨【内部特殊细节】

左侧三张图片左上角添加黑色或深灰色半透明标题条，使用白色中文无衬线字体：

“内部全景图”
“内部反向视图”
“室内俯视布局（含标注）”

右侧约占总宽度52%–53%，采用严格3列×2行六宫格，共六张细节图。所有细节图都必须拍摄于【指定空间】内部，不能展示外部环境。

①【内部核心区域】（主要功能）

③【内部座椅或使用区域】（使用空间）

第二行展示：

④【内部材质细节】（材质与纹理）
⑤【内部灯光细节】（光源与氛围）
⑥【内部收纳或连接结构】（功能细节）

每张细节图左上角添加黑色半透明标题条，格式为：

“① 名称（功能说明）”

所有图像必须保持同一内部空间、同一比例、同一材质、同一时间、同一光线方向和同一设计逻辑。主图、反向视图、俯视图和细节图必须相互对应，重点帮助视频模型识别内部空间结构、材质、设备位置和镜头范围。

图片之间使用5–8px纯白色分隔线。不使用圆角卡片、阴影、复杂边框或装饰性UI。不出现人物、动物或其他生物。

最终要求：
空间范围严格限定在【指定空间】内部；
所有镜头均位于内部；
所有细节图均为内部局部；
不得显示外部环境；
不得扩展场景边界；
不得生成完整车辆、完整建筑、道路、赛车场、城市、停车场或远景场地；
无水印、无Logo、无品牌标志、无人物、无动物、无不相关物品。
```

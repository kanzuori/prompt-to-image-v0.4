# Template variables

仅用于绑定 【】 槽位：道具名称、时代或世界观、主要材质、颜色与视觉风格、功能、磨损细节与使用场景信息（仅用于材质和磨损参考，不生成环境）。不得发送给图像工具。

---

# Image prompt

```text
16:9横向道具概念设计拆解板，professional prop design breakdown sheet，prop design bible，product detail presentation board，cinematic production design reference sheet。

整张画面采用严格模块化网格布局，满版图片拼贴，极窄白色分隔线，几乎没有外围留白。整体排版规整、对齐精准、信息层级清晰，像高端影视美术设定集、AAA游戏道具设计稿和专业产品材质展示板。

左侧约占总宽度50%，设置一张大型主视图，完整展示【道具名称】的整体外观、比例、结构和主要材质。主图使用专业商业摄影或电影级概念设计构图，主体完整，使用无干扰背景，不放置于实际场景中，光线清晰，能够准确识别道具的整体形态。

右侧约占总宽度50%，划分为2列×3行六个细节展示区域。六张细节图分别展示：

1. 整体结构或主要功能
2. 正面或核心部件
3. 侧面、背面或连接结构
4. 材质与表面纹理
5. 关键装饰、标志或工艺细节
6. 使用状态、收纳状态或尺度参照

每张细节图都必须与左侧主图保持完全一致的道具身份、尺寸比例、颜色、材质、纹理、结构、磨损痕迹和光线逻辑。细节图应使用不同角度、不同景别和局部特写，清楚呈现道具的设计信息，避免重复画面。

左侧主图和右侧六张细节图的左上角均添加黑色或深灰色半透明矩形标题标签，使用简洁清晰的白色中文无衬线字体。标题根据道具内容自动生成，例如：
“全景图”
“结构细节”
“材质细节”
“连接方式”
“装饰细节”
“使用展示”
“收纳展示”
“功能部件”
“磨损细节”。

图片之间使用约5–8px纯白色分隔线，所有图片严格网格对齐。不得使用圆角卡片、阴影、复杂边框、装饰性UI或无关图标。文字仅用于区域标注，不添加说明段落。

整体风格为专业道具设计资料板、影视美术制作参考图、AAA游戏资产设计稿、电影Production Design presentation、产品材质拆解图。高细节、真实材质、统一光照、清晰结构、专业构图、视觉信息密度高。

道具内容：
【填写道具名称】
【填写时代或世界观】
【填写主要材质】
【填写颜色与视觉风格】
【填写功能】
【填写磨损、污渍或特殊细节】
【填写使用场景信息（仅作材质和磨损参考）】

要求：同一道具贯穿所有画面，保持结构和细节一致；无人物、无动物、无水印、无Logo、无品牌标志、无多余文字、无不相关物品、无结构变形、无重复角度。
```
